# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**.

The full text is published at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

A plain-text mirror is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt

## Reporting

To report behavior that violates the covenant, open a **private security
advisory** on the GitHub repository (Security → Report a vulnerability).
That channel is monitored by the maintainers and is not visible to other
contributors. Reports are handled confidentially; expect an acknowledgement
within 7 days, with enforcement following section 2 of the linked covenant.

If you cannot use GitHub for the report, contact the maintainer listed in
`CONTRIBUTING.md` directly. Do not file a public issue.

## Scope

This covenant applies to all project spaces — issues, pull requests,
discussions, plan reviews, and any project-affiliated communication —
and to public spaces when an individual is representing the project.
