## Cross-Functional Teams

Real work doesn't happen in silos. When a task requires multiple perspectives, assemble a team. Name the mission, assign roles, define the deliverable.

### How Teams Work — Decision Protocol

1. **Lead** states goal + constraints
2. **Advisors** provide max 3 bullets each (perspective, risks, recommendations)
3. **Lead** decides with stated confidence level
4. **Next check-in trigger** defined (metric, date, or event)

This prevents role thrash. One lead, focused advice, clear decision.

### "Done" Criteria

Every mission must define what artifact marks completion: merged PR, deployed feature, published report, measured KPI. No open-ended wandering.

### Team Templates

**Product Launch** (new feature or app release)
- Lead: Product Manager
- Team: Frontend Engineer, Backend Engineer, Designer, QA Engineer
- Deliverable: Shipped feature with passing tests and updated docs

**Technical Spike** (evaluating a new technology or approach)
- Lead: Software Architect
- Team: Research Scientist, Backend Engineer, Security Engineer
- Deliverable: Decision document with recommendation, trade-offs, and prototype

**Growth Experiment** (testing a hypothesis about user behavior)
- Lead: Growth Strategist
- Team: Data Engineer, Frontend Engineer, Content Creator
- Deliverable: A/B test deployed, measurement plan documented, results analyzed

**Incident Response** (something is broken in production)
- Lead: Infrastructure / SRE

- Deliverable: Issue resolved, post-mortem written, prevention measures implemented

**Market Research Sprint** (evaluating a trade, market, or investment)
- Lead: Quantitative Analyst
- Team: Research Scientist, Market Analyst, Business Analyst

**Sunsetting Product** (winding down a product)

- Team: Business Analyst, Compliance, Data Engineer

## Bell Labs Operating Model

Cross-functional thinking, not silos. The best breakthroughs happen when people with different expertise collide.

- **Diverse expertise, shared mission.** Pair a quant with a product person. Put a security engineer in every design review.
- **Loonshots vs franchises.** Protect radical ideas from the gravitational pull of what's already working. Both matter — don't let one starve the other.
- **10x thinking.** Don't ask "how do we improve this by 10%?" Ask "how would we make this 10x better?" The 10x answer forces you to rethink assumptions.

**Required Artifacts:**

- **Decision Record** — Context, options considered, decision, confidence level, review trigger.
- **Experiment Record** — Hypothesis, metric, design, duration, outcome, next action.
- **Postmortem** — Trigger, timeline, root cause, counterfactuals, prevention actions.
- **Risk Register** — Threat, likelihood, impact, mitigation, owner, review date.

    57	        return sum(
    58	            1
    59	            for fr in self.features
    60	            for flag in fr.scope.flags
    61	            if flag.severity == "block"
    62	        )
    63	
    64	    def flag_count(self) -> int:
    65	        return sum(len(fr.scope.flags) for fr in self.features)
    66	
    67	    def flagged(self) -> tuple[FeatureScopeReport, ...]:
    68	        """The feature reports that fired at least one flag, in plan order."""
    69	        return tuple(fr for fr in self.features if fr.scope.flags)
    70	
    71	    def to_dict(self) -> dict:
    72	        """Machine-readable rendering (acceptance #1 — same data as text)."""
    73	        return {
    74	            "plan_id": self.plan_id,
    75	            "summary": {
    76	                "feature_count": len(self.features),
    77	                "flagged_feature_count": len(self.flagged()),
    78	                "flag_count": self.flag_count(),
    79	                "block_flag_count": self.block_flag_count(),
    80	                "has_block": self.has_block(),
    81	            },
    82	            "features": [_feature_to_dict(fr) for fr in self.features],
    83	        }

    89	def build_plan_scope_report(
    90	    plan_id: str,
    91	    features: Iterable[dict],
    92	    resolvers: Resolvers | None = None,
    93	) -> PlanScopeReport:
    94	    """Lint every feature and propose a split for each, assembling the report.
    95	
    96	    Pure: no network, no filesystem, no mutation of the inputs. F001 runs over
    97	    every feature; F002 runs over every feature too and yields ``None`` for the
    98	    in-budget single-surface ones, so the proposal is present exactly for the
    99	    over-scoped (flagged) features.
   100	    """
   101	    feature_reports: list[FeatureScopeReport] = []
   102	    for feature in features:
   103	        scope = lint_feature(feature, resolvers)
   104	        split = propose_split(feature, scope)
   105	        feature_reports.append(FeatureScopeReport(scope=scope, split=split))
   106	    return PlanScopeReport(plan_id=plan_id, features=tuple(feature_reports))

   109	def render_text(report: PlanScopeReport) -> str:
   110	    """Human-triage rendering of a :class:`PlanScopeReport`.
   111	
   112	    Built from the same typed data as :meth:`PlanScopeReport.to_dict`
   113	    (acceptance #1). Deterministic — flags and features stay in plan order.
   114	    """
   115	    lines: list[str] = []
   116	    lines.append(f"plan-review: {report.plan_id}")
   117	    lines.append(
   118	        f"  {len(report.features)} feature(s), "
   119	        f"{len(report.flagged())} flagged, "
   120	        f"{report.flag_count()} flag(s) "
   121	        f"({report.block_flag_count()} block-severity)"
   122	    )
   123	    verdict = "BLOCK" if report.has_block() else "OK"
   124	    lines.append(f"  verdict: {verdict}")
   125	    lines.append("")
   126	
   127	    if not report.flagged():
   128	        lines.append("No scope flags — every feature is single-surface and in-budget.")
   129	        return "\n".join(lines) + "\n"
   130	
   131	    for fr in report.features:
   132	        scope = fr.scope
   133	        if not scope.flags:
   134	            continue
   135	        lines.append(
   136	            f"{scope.feature_id or '(unnamed)'} "
   137	            f"[{', '.join(scope.surfaces)}] — {scope.ac_count} AC(s)"
   138	        )
   139	        for flag in scope.flags:
   140	            lines.append(f"  [{flag.severity}] {flag.kind}: {flag.evidence}")
   141	        if fr.split is not None:
   142	            lines.extend(_render_split_text(fr.split))
   143	        lines.append("")
   144	
   145	    return "\n".join(lines).rstrip("\n") + "\n"

   188	def _gather_codebase_vocabulary(package_dir: Path) -> tuple[frozenset[str], frozenset[str]]:
   189	    """Collect the real symbol + flag vocabulary the ``dontpanic_orchestrate``
   190	    package actually declares, by AST-walking its sources.
   191	
   192	    Returns ``(symbols, flags)``:
   193	
   194	      * ``symbols`` — every ``def`` / ``class`` name, module- and class-level
   195	        assignment target, and ``Literal[...]`` string member (so a feature
   196	        naming a real function like ``lint_feature`` or a declared taxonomy
   197	        value like ``over_surface`` resolves instead of false-flagging
   198	        ``missing_prereq``).
   199	      * ``flags`` — every ``--name`` string literal in the sources (catches CLI
   200	        flags the curated ``known_flags`` list hasn't caught up to, e.g.
   201	        ``--allow-oversize``).
   202	
   203	    This is the "resolve against what the system really declares" step. A token
   204	    that exists *nowhere* in the package still fails to resolve — so the F012
   205	    silent-prerequisite signal (a stale/undeclared capability) is preserved.
   206	    Tests directories are skipped so test-only helpers don't pollute the set.
   207	    """
   208	    import ast
   209	
   210	    symbols: set[str] = set()
   211	    flags: set[str] = set()
   212	    for path in package_dir.rglob("*.py"):
   213	        parts = set(path.parts)
   214	        if "__pycache__" in parts or "tests" in parts:
   215	            continue
   216	        try:
   217	            tree = ast.parse(path.read_text(), filename=str(path))
   218	        except (SyntaxError, UnicodeDecodeError):
   219	            continue
   220	        for node in ast.walk(tree):
   221	            if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)):
   222	                symbols.add(node.name)
   223	            elif isinstance(node, ast.AnnAssign) and isinstance(node.target, ast.Name):
   224	                symbols.add(node.target.id)
   225	            elif isinstance(node, ast.Assign):
   226	                for tgt in node.targets:
   227	                    if isinstance(tgt, ast.Name):
   228	                        symbols.add(tgt.id)
   229	            elif isinstance(node, ast.Subscript) and isinstance(node.value, ast.Name) and node.value.id == "Literal":
   230	                for const in ast.walk(node.slice):
   231	                    if isinstance(const, ast.Constant) and isinstance(const.value, str):
   232	                        symbols.add(const.value)
   233	            elif isinstance(node, ast.Constant) and isinstance(node.value, str):
   234	                if node.value.startswith("--") and len(node.value) > 2:
   235	                    flags.add(node.value.split()[0])
   236	    return frozenset(symbols), frozenset(flags)
   237

   240	    """Wire the three real resolver sources F003 consults (lint.Resolvers doc).
   241

   243	    exactly the "wire in the real sources" step the CLI layer performs once
