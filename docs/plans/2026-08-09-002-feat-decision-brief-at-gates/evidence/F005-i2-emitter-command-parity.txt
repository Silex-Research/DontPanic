== 0. Why this evidence exists ==

Acceptance 7 says every exact command is byte-identical before and after F005.
The render-level baseline (fixtures/f005_prechange_render.json) cannot prove it
alone: it re-renders events the *test module* builds, whose technical_metadata
supplies more than production does, so a change made at an emit site moves the
live command while that baseline stays put. Audit i0 caught exactly that.

fixtures/f005_prechange_emitter_commands.json closes the hole by driving the
real emitters. This file proves three things about it: that it is a genuine
pre-change capture (A), that the post-change tree still matches it (B), and
that it would fail if the command did move (C).
